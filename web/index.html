AButton Setup

Set up an Echo Button running AButton firmware, right from your browser.

This browser can't use Bluetooth

Open this page in Chrome or Edge on Windows, macOS, ChromeOS, Android or Linux. Safari, Firefox and every browser on iPhone and iPad lack Web Bluetooth.

The page also has to be opened over https:// or from localhost.

Before you start

  1. The button runs AButton 0.2.0 or newer (0.3.0+ for encryption).
  2. It's switched on: press it once to wake it up.
  3. Nothing else is connected to it. The button takes one connection at a time, so Home Assistant can't change its light while this page is connected.

On Linux, Chrome may need chrome://flags/#enable-web-bluetooth turned on. Not in the list?

AButton

BTHome encryption …

This firmware can't encrypt. Update the button to AButton 0.3.0 or newer.

With encryption on, nobody nearby can read your presses or fake them. Home Assistant's BTHome integration then needs the button's key.

First press the button once. For safety, the button only accepts a key change within 60 seconds of a press. That press counts like any other, so it may run your automations.
Use a key I already have

Encryption is on. The button's key:

Save it now. The button never shows it again.

In Home Assistant:

  1. Open Settings → Devices & services. The BTHome integration asks for this button's key within a minute (look for a notice to re-authenticate or reconfigure it).
  2. Paste the key and submit. Presses and battery work again, now encrypted.

Adding the button to BTHome for the first time? Home Assistant asks for the key when you add it.

Encryption is off. Once Home Assistant has a key, it ignores unencrypted adverts as a safety measure. Delete the button's BTHome device in Home Assistant and add it again, without a key.

Light

Repeat 0 loops until stopped. Animations play over the steady color, which comes back after them.

Custom animation
Steps are COLOR:MS, or COLOR:MS:fade to fade into the color; up to 40.

Settings

Name

Up to 26 characters (plain letters, digits and punctuation). Adverts carry the first 15 (7 with encryption on); Home Assistant reads the full name.

Maintenance

Restore defaults resets the settings, name and steady color. It keeps the encryption key.

Not connected.
Everything happens between this page and your button over Bluetooth; nothing is sent anywhere else. Command-line equivalent: firmware/abutton_ble.py.
